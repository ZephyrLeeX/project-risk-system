## 2. 已验收能力

### 2.1 工程与数据库

- Vue 3 + TypeScript + Vite 前端工程；
- NestJS + TypeScript API 工程；
- Prisma + PostgreSQL 数据访问层；
- 前后端共享契约包；
- Docker Compose 本地 PostgreSQL 环境；
- 环境变量初始化、数据库迁移、种子数据和统一质量检查脚本。

### 2.2 认证与会话安全

- 账号密码登录、会话恢复、退出和修改密码；
- HttpOnly 会话 Cookie；
- Cookie 使用 `SameSite=Lax`、根路径和明确过期时间；
- 开发环境不设置 `Secure`，生产环境按配置启用；
- 会话令牌仅以哈希形式入库；
- 会话中的客户端 IP 使用不可逆摘要，不保存原始 IP；
- 连续失败5次后锁定30分钟；
- 管理员解锁后失败次数和锁定时间正确复位；
- 首次登录和密码重置后强制修改密码；
- 修改密码、重置密码和停用账号后撤销已有会话；
- 过期令牌、篡改令牌和退出后的令牌均不可继续访问；
- 非可信 Origin 的写请求被 CSRF 防护拒绝。

### 2.3 后台管理与 RBAC

- 用户查询、筛选、创建、编辑、启停、解锁和密码重置；
- 角色查看、创建、复制、编辑、启停和受约束删除；
- 权限分组配置；
- 全部项目、本人负责、被授权、本人负责及授权、无项目数据五类范围；
- 前端路由守卫与后端接口权限守卫；
- 角色停用实时生效；
- 用户停用后会话实时撤销；
- 普通用户访问后台管理接口返回403。
