# 阶段一第1步：工程基线

## 本步范围

本步只建立可持续开发的正式工程，不实现登录、用户、角色等业务接口。

已建立：

1. pnpm monorepo；
2. Vue 3 + TypeScript + Vite 前端；
3. NestJS + TypeScript API；
4. Prisma + PostgreSQL 数据模型骨架；
5. 前后端共享契约；
6. Docker Compose 数据库配置；
7. Excel、邮件和备份存储目录；
8. 类型检查、测试和构建脚本。

## 原型边界

上一级 `ui-prototype` 是11页视觉与交互基线，不能直接复制其中的模拟数据作为生产数据，也不能继续在正式工程中使用浏览器内数组承担业务存储。

## 下一步

阶段一第2步实现：

1. 数据库首个迁移与默认角色、权限种子；
2. 登录、服务端会话和首次修改密码；
3. 登录失败锁定与密码策略；
4. 登录和会话审计；
5. 前端登录页接入真实API。
