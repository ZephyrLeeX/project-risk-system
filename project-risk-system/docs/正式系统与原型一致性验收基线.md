# 正式系统与原型一致性验收基线

## 1. 强制原则

`/Users/mianmiannuan/Documents/workspace/项目风险管理平台/ui-prototype` 是正式系统唯一的界面与布局基准。

- 开发只负责接入真实数据、权限、接口、状态与交互，不得自行重排页面结构。
- 页面导航、信息层级、卡片顺序、表格字段、抽屉、弹框、按钮主次、文案和响应式断点均以对应原型页为准。
- 如真实数据需要补充状态，只能在原型既有区域内扩展，不得删除或替换原功能模块。
- 所有页面及弹框最小字号不得低于 12px。
- 手机端必须按原型的移动端布局重排，不允许把多列表格直接压缩成竖排文字。
- 对原型有业务疑问时先确认，不以开发者个人偏好修改布局。

## 3. 单页验收清单

每一页进入“完成”状态前必须同时满足：

1. 桌面端页面结构与对应原型逐区块一致。
2. 390×844 手机视口无页面级横向溢出。
3. 可见文字最小字号不低于 12px。
4. 原型中的功能模块、字段和详情内容无删减。
5. 真实接口的加载、空状态、错误状态、权限状态均在原型结构内展示。
6. 主要按钮、筛选、表格/卡片、弹框、抽屉和导航交互可操作。
7. 浏览器控制台无应用错误，全量类型检查、测试和生产构建通过。
