# 使用可配置的 OpenAI-compatible AI Provider

周报风险提取与 Agent 使用统一的 OpenAI-compatible Provider 接口，同时支持公网服务和内网私有模型，由管理员配置服务地址、模型、密钥和默认 Provider。该边界避免业务能力绑定单一厂商，也允许按数据安全要求切换到内网模型。

## Consequences

- 密钥只保存在部署环境的受保护配置中，接口和日志不得返回明文。
- 没有已启用且健康的 Provider、调用超时或结构化结果校验失败时，业务必须显示真实失败状态并允许重试，不得生成模拟结果。
- 自动化测试可以使用替身 Provider，但 MVP 验收必须使用真实测试邮箱和真实 Provider 跑通邮件到风险发布的完整链路。
- 所有模型输出均视为不可信输入；查询必须再次执行项目权限过滤，写操作必须通过结构化校验与用户确认。
