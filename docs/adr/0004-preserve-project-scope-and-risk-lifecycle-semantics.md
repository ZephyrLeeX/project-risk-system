# 保持现有项目范围与两态风险生命周期

FastAPI 重写继续使用现有五种项目数据范围，不实现旧规格中的“指定部门”；正式风险继续采用“跟踪中”和“已解除”两种状态，不采用旧规格中的四阶段状态。当前前端和共享契约已经稳定体现这套语义，且项目授权与部门归属不应隐式绑定，风险处置进度应由管理者待办和风险时间线表达。

## Consequences

- 项目范围包括全部、本人负责、指定项目、本人负责及指定项目、无权限五类。
- 菜单权限和项目数据范围分别校验，所有列表、统计、详情和 Agent 查询使用相同的项目过滤规则。
- 风险只能在跟踪中与已解除之间转换；重新出现的已解除风险可以被重新打开。
- “新增”“持续”“缓解中”等信息可以作为时间线事件或处置描述，但不是正式风险状态。
