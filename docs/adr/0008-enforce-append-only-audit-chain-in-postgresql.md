# 在 PostgreSQL 中强制追加式审计哈希链

FastAPI 重写保留现有数据库级防篡改审计：应用记录有业务含义的审计事件，PostgreSQL 触发器禁止更新和删除审计记录，并将每条记录连接到前一条记录的哈希。单纯依赖应用日志无法防止拥有应用权限的代码修改历史记录。

## Consequences

- 所有敏感写操作及失败操作必须写入统一审计服务，并携带操作者、资源、结果、追踪编号和脱敏快照。
- 系统提供哈希链完整性检查；发现断链必须产生明确告警，不能自动修复或覆盖证据。
- 审计导出必须脱敏，且导出行为本身也进入审计链。
- 数据清理、测试夹具和运维脚本不得绕过审计表的只增不改约束。
