# 限制 Agent 只能调用授权业务工具

Agent 只负责自然语言意图识别、参数抽取和回答组织，所有查询和写入均通过已有权限控制与领域规则的白名单业务工具完成，禁止模型生成或执行任意 SQL。该边界确保 Agent 是业务入口而不是绕过系统规则的旁路。

## Consequences

- 查询在每次调用时重新执行菜单权限和项目数据范围校验，回答标明数据时间与业务依据。
- 上报、处理和解除风险先生成结构化预览；确认凭证绑定用户、会话和操作内容，短时过期且只能使用一次。
- 工具调用必须幂等并记录追踪编号；模型重试不得造成重复写入。
- AI 未配置、超时或失败不影响看板、导入和风险维护等非 AI 功能。
