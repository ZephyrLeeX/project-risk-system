# 分阶段将接口契约权威迁移到 OpenAPI

后端迁移期间，现有 TypeScript 共享契约和前端可观察行为是 FastAPI 的兼容基准；整体切换完成后，FastAPI 生成的 OpenAPI 文档成为唯一接口契约来源，并自动生成前端类型。该过渡既避免重写期间强迫前端同步重构，也防止切换后长期手工维护两套类型。

## Consequences

- 每个迁移模块必须具有旧接口与 FastAPI 的请求、响应、状态码和错误语义对照测试。
- 模块完成还要求 Python 单元测试、PostgreSQL 集成测试、真实前端页面端到端测试、权限负向测试和静态检查通过。
- OpenAPI 成为权威前，不得删除或擅自改变现有 TypeScript 契约；成为权威后，生成产物不得手工修改。
- Mock 只用于隔离外部依赖，不能作为业务验收成功的证据。
