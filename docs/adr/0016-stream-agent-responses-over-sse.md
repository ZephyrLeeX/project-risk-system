# 使用 SSE 流式返回 Agent 响应

Agent 使用 Server-Sent Events 流式返回文本、进度和结构化预览事件，真正的写操作确认仍通过普通 REST 接口完成。SSE 满足现有对话界面的单向流式反馈需求，同时比 WebSocket 更容易在单机反向代理、Cookie 会话和断线重连场景中运维。

## Consequences

- SSE 事件具有稳定类型和结构，包含会话、消息及追踪标识；客户端必须能处理断线、超时和明确的失败事件。
- 流式连接只产生回答或操作预览，不能在流中隐式提交风险写操作。
- 上报、处理和解除风险使用独立 REST 确认接口，并继续遵守一次性确认凭证、幂等与审计要求。
- 前端仅做真实接口接线及加载、空状态、失败、重试和确认反馈，不重做现有视觉设计。
