# 最小化留存邮件内容

系统解析周报邮件后只长期保存安全摘要、关键要点、必要证据摘录和附件元数据，不保存完整邮件正文与附件。该选择降低敏感业务数据泄露和备份扩散风险；需要重试或重新分析时，系统按邮箱和 IMAP UID 重新读取原邮件。

## Consequences

- 邮箱中的原邮件被删除或 UID 失效后，系统无法再次提取完整内容。
- 正式风险必须保存足以解释其来源的必要证据摘录和对应邮件元数据。
- 日志、审计快照和 AI 调用记录不得间接保存完整邮件、附件文本、完整提示词或模型原始响应。
- 自动化清理任务应删除处理过程中产生的临时文件，即使任务失败或 Worker 重启。
