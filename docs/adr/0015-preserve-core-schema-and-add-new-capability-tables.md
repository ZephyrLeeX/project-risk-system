# 保持核心表兼容并为新能力增加表

FastAPI 首期保持现有用户、权限、项目、导入、风险、待办、邮箱和审计等成熟 PostgreSQL 表、字段、枚举与约束，并以当前结构建立 Alembic 基线。Agent 会话、一次性确认凭证和真实周报聚合等新增能力使用新表，不为重写而全面重造核心数据模型。

## Consequences

- 核心业务模型先验证与 Prisma 结构的等价性，切换前只做向后兼容的增量变更。
- 新表必须遵守现有 UUID、UTC 时间、审计、项目数据范围和删除策略。
- 当前仅有演示数据，正式环境从 FastAPI 的 Alembic 基线和 Seed 创建，不迁移旧库内容。
