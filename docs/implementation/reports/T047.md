## 结论

## 实现

### 核心 — `todos/service.py`

`list()` 重写为 SQL-layer 分页，移除原 `_rows()` 与双物化：

- **items 查询**：`self._statement(filtered).order_by(*order).offset((query.page - 1) * query.pageSize).limit(query.pageSize)` — 单次有界查询，无全量物化。
- **total**：独立 `select(func.count(ActionItem.id))`，与 items 同 `filtered` 条件（owner/status 过滤 + scope），join `Project`（inner）+ `User`（outer）—— 唯一被 `or_` owner 过滤与 scope predicate 引用的 join；省略的 `Department`/`Risk`/`RiskCategory` 均为 unique-FK left join，不会放大行数，故 count == items 基数。
- **summary/updatedAt**：`_scoped_summary` 单条 SQL aggregate（`func.count()` + `func.count().filter(...)` per status + `func.max(updatedAt)`），over **full scoped set**（仅 `scope_predicate`，不含 owner/status 过滤）—— 保留原 summary/owners 跨过滤稳定的行为。
- **owners**：`_scoped_owners` `select(func.coalesce(User.displayName, ActionItem.assigneeNameSource, literal("待分配"))).distinct()` over full scoped set。
- **schedule**：`_schedule_items` bounded top-5 active（`status != COMPLETED`）`LIMIT 5` 查询，不物化全量 filtered 集。
- **order**：`(status.asc(), urgency.asc(), dueDate.asc(), updatedAt.desc(), id.asc())` — `id.asc()` 为确定性 tiebreaker，保证分页跨页无重复/缺失。
- `_filtered_conditions` helper 集中 owner/status + scope 条件，items 与 count 共用，避免 filter 漂移。

## PostgreSQL 16 分页验证（`tests/todos/test_todos_pagination.py`，新文件）

针对真实 PostgreSQL 16 + 隔离 per-run schema（`t047_<uuid>` / `t047large_<uuid>` + Alembic `upgrade head`），10 tests 全 PASS：

- first/middle/last page 覆盖全部行、跨页无重复/无缺失（25 controlled todos，pageSize=10）。
- 默认 page=1 / pageSize=20；empty page beyond last（page=4 → `items==[]`，`total` 仍 25）。
- status filter（IN_PROGRESS → total=8）+ owner filter（张三 → total=12）与分页联合。
- summary/owners 在 filter 下仍反映 full scoped set（`total`=10 filtered，`summary.total`=25，owners={"张三","李四","待分配"}）。
- DataScope：ALL scope 见 3 active projects 的 todos（total=27）不含 archived；OWNED scope 仅 25（排除 assigned/other/archived）。
- 稳定确定性排序：重复请求同序；首页前 8 项无 COMPLETED。
- **大数据 fixture（500 todos）SQL LIMIT/OFFSET 证明**：`before_cursor_execute` event listener 捕获语句，断言恰好 1 条 `LIMIT`+`OFFSET` 语句（items），1 条 `count(` 无 `LIMIT`（total），无语句物化全量 500 行集。
- **scoped performance smoke**：page=1/pageSize=20 < 2.0s（明确标注 "not an ADR 0032 gate"，非 T038 PASS）。

### Non-blocking nits（不阻断 checkpoint，honest disclosure）

1. **`_scoped_owners` 空串边界** — `coalesce(User.displayName, assigneeNameSource, "待分配")` 与原 `item.assigneeName = assigneeNameSource or "待分配"` 在 `assigneeNameSource` 为空串（非 NULL）时分歧。app 代码从不写入空串（`default_assignee_for_risk`/`UpdateTodoRequest` 拒空），故理论边界，正常数据无 failure scenario。
