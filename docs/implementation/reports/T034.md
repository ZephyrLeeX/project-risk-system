## 实施

### Write-set（business frontend API/views/composables/utils/tests only）

- `apps/web/src/api/weekly-reports.ts`（新）：`weeklyReportsApi.current()/report(weekStart)/detail(weekStart, projectId)`，全部消费 generated `WeeklyReportResponse`/`WeeklyProjectDetail`/`WeeklyProjectSummary`/`WeeklyReportItemResponse`/`WeeklyProject`（`OpenApi.components["schemas"][...]`），非手写替代契约。
- `apps/web/src/api/agent.ts`（新）：`agentApi.help()/create()/continueConversation()/history()/messages()/confirm(token)`，全部消费 generated agent 类型；`confirm` 以空 `{}` 请求体（`AgentConfirmationRequest`）调用 `POST /agent/confirmations/{token}`。
- `apps/web/src/utils/agent-sse.ts`（新）：纯 SSE 帧解析（`parseSseFrames`，处理 `\n\n` 边界、CRLF 归一、多行 data、跨 chunk carry）+ 事件 reducer（`applyFrame`，覆盖 `message.delta`/`progress`/`preview`/`completed`/`error`/`heartbeat`）+ 显示标签（`agentErrorLabel`/`confirmationErrorLabel`/`operationLabel`/`previewSummary`）。SSE stream 在 OpenAPI 中为 `text/event-stream: unknown`，故以运行时类型守卫窄化 wire payload，全程无 `any`。
- `apps/web/src/utils/weekly-reports.ts`（新）：纯展示 helpers（`summaryCount`/`levelCount`/`levelCountsLabel`/`weekRangeLabel`/`staleLabel`/`riskStatusLabel`/`todoStatusLabel`/`projectHasRisks`），对 opaque `summary`/`riskLevelCounts` map 做运行时窄化。
- `apps/web/src/composables/useAgentConversation.ts`（新）：Agent 会话控制器。将 `agentApi` REST 与 PostgreSQL-backed SSE stream 接入纯 reducer；持有 create/continue、resume-after-disconnect（`after=lastEventId`）、retry-after-provider-failure、one-use preview confirmation 生命周期。stream 只读消费，不在 stream 上写。
- `apps/web/src/views/DashboardView.vue`：
  - 移除本地伪造 `sendAgent` 应答链（high-risk/回款/else 分支）与静态 `weeklyReports` 5 行数组。
  - 周报面板消费 `weeklyReportsApi.current()` 真实 `WeeklyReportResponse`：header 显示 week 范围 + reportCount/riskCount 汇总；表体为 `projects[]`（项目名/风险数/等级分布/操作），点击有风险项目打开 `WeeklyProjectDetail` 明细 modal。
  - 周报明细 modal 消费 `WeeklyProjectDetail.items[]`（summary/riskLevel/riskStatus/todoStatus/occurredAt）。
  - Agent 抽屉消费 `useAgentConversation`：messages（user/assistant）+ streaming 文本（`message.delta` 累积）+ progress + preview 卡片（`operationLabel`/`previewSummary` + 确认按钮 + 成功/失败反馈）+ error（`agentErrorLabel` + retryable 重试）+ disconnect（重新连接）+ 输入表单。
  - 权限：Agent 入口按 `agent.use` 网关（`canUseAgent`）；周报随页面 `dashboard.view` 守卫；邮箱同步链接保留 `mailbox.sync_self`（未回归）。
  - loading/empty/error/stale 语义：周报面板 loading/error(含 503 `WEEKLY_REPORT_STALE` 经由 error 分支 + 重试)/empty/data(stale 内联标记)；Agent 抽屉 loading/streaming/progress/error/disconnected/preview。
  - `onMounted` 增加 `loadWeeklyReport()`；`onUnmounted` 调用 `agent.reset()` 释放 stream（composable 亦经 `onScopeDispose` 自动 abort）。
- `apps/web/src/utils/agent-sse.test.ts`（新）：15 个 vitest，覆盖 parser（跨 chunk carry、CRLF、comment、默认 event）、reducer（delta 累积、progress、completed 终结、preview 解析、error 终结、heartbeat no-op、unparseable 帧游标推进、resume-safety）、execution/confirmation 错误标签、operation 标签、preview 摘要。
- `apps/web/src/utils/weekly-reports.test.ts`（新）：8 个 vitest，覆盖 summary/level 计数窄化（number/string 形态）、等级分布行、week 范围、stale 标签、risk/todo 状态标签、projectHasRisks。
