## 实施摘要

在 Python mailbox 模块实现 ADR 0024 固定 allowlist 的受限邮件/附件解析、ADR 0022 source identity 重抓、确定性标准项目/活跃别名匹配，以及 metadata-only 附件终态。只允许 `.txt`、`.pdf`、`.docx`、`.xlsx` 的扩展名、声明 MIME 和内容识别三者一致；OOXML 进行 ZIP 限制预检与 `defusedxml` 读取，PDF 仅以无网络 helper 提取文本。所有 helper 均受 CPU、地址空间、文件大小和 wall-clock 上限约束；邮件、附件、日志、Celery payload 和 audit 不保存 raw content。

解析阶段按 `(mailbox_config_id, uid_validity, imap_uid)` 重新抓取 source。source 缺失和 UIDVALIDITY 变化保存为精确 `PERMANENT_FAILURE`；可恢复运行时故障保存为 `RETRYABLE_FAILURE`。临时目录为 owner-only、随机命名，task `finally`、worker startup/execute 与 durable reconciliation 均清理遗留目录。
