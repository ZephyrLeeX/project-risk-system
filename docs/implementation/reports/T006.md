## Review 历史

### 初审：`REVIEW_FAILED`

- `TRUNCATE` 可绕过 UPDATE/DELETE row trigger，清空 audit evidence。
- 自然嵌套的 `mail.body`、`attachment.text`、`model.response` 会绕过脱敏。

### 第 1/2 轮修复复审：`REVIEW_FAILED`

- PostgreSQL `TRUNCATE` 拒绝已修复并通过。
- 脱敏仍遗漏复数、复合键和相邻路径，例如 `attachments[].text`、`mail.htmlBody`、
  `messages[].content`、`model.completion`。

### 第 2/2 轮修复最终复审：`REVIEW_FAILED`

最终阻断证据：

- `model.result` 和根级 `completion` 仍可能原样保存模型输出；
- `mailMessage.bodySize`、`mailMessage.contentType`、`email_messages[].textLength`、
  `attachment-files[].content-type`、`providerModel.outputTokenCount`、
  `providerModel.responseTimeMs` 等 metadata 被错误脱敏；
- structured `LLMResponse` 可能整体被替换，导致 `requestId`、model name、latency 等
  metadata 丢失。

该结果违反“禁止保存模型原始响应”与“保留非敏感 metadata”的安全/可用性边界。两轮修复额度
已用尽，按执行规则将 T006 标记为 `BLOCKED`，不再继续修复。

### 架构变更

人工批准 ADR 0017 取消 redacted snapshot audit，改为 fixed typed metadata-only audit。上述
`REVIEW_FAILED`、`BLOCKED`、两轮修复和 remediation 历史全部保留；本节记录新的恢复结果，不覆盖
旧失败证据。

最终 Audit 持久化字段：

- `id`
- `createdAt`
- `actorUserId`
- `actorType`
- `module`
- `action`
- `resourceType`
- `resourceId`
- `result`
- `traceId`
- `requestId`
- `projectId`
- `failureCode`
- `previousHash`
- `integrityHash`

`AuditEvent` 仅接受对应的 typed business input，使用 strict/frozen/extra-forbid validation；数据库
enum、UUID、长度、字符集和 identity checks 形成第二层边界。

## 2026-08-11 Wave 7 Integration Remediation

- Root cause：pgcrypto 未显式指定安装 schema，hash function 使用未限定的 `digest(...)`；隔离
  schema 的 `search_path` 无法解析位于 `public` 的扩展函数。
- Fix：改为 `CREATE EXTENSION IF NOT EXISTS pgcrypto WITH SCHEMA public`，并在
  `audit_log_compute_hash` 中使用 `public.digest(...)`。未发现同一 migration 中其他类似扩展函数引用。
- Contract impact：无；metadata-only audit contract、hash semantics、snapshot/redaction 约束均未改变。
- Regression：新增 isolated-schema、`search_path` 不含 `public` 的 upgrade/hash insert test。
- Independent Review：`REVIEW_PASSED`，仅复核 T006 migration diff、regression 和 PostgreSQL upgrade。
- Focused validation：真实 PostgreSQL 16 下 T006/audit/schema tests `11 passed`；isolated-schema
  empty upgrade、`current`、`check` 均 `PASS`。
