T045 恢复 `_Contract` serialization-mode schema fidelity 后，frozen OpenAPI authority 中 `AdminOverview`/`HealthItem`/`AttentionItem`/`RecentAuditItem`/`UnavailableSection`/`OverviewLink` 均为真实类型（无 `unknown`），T033 stop condition「A required view field is absent from the approved contract」不再触发。本轮在 Lean Execution Mode 下完成 T033 实施：admin 概览页消费 `GET /api/admin/overview` 生成契约，移除固定 health/attention/audit 业务数组，保留既有权限/路由/metrics，补齐 loading/empty/error/unavailable 语义。Independent Review = `REVIEW_PASSED`。

## 实施

### Write-set（admin frontend files/tests only）

- `apps/web/src/api/admin.ts`：新增 `adminApi.overview()`（`GET /admin/overview`）；新增 6 个 generated-type 别名 `AdminOverview`/`HealthItem`/`AttentionItem`/`RecentAuditItem`/`UnavailableSection`/`OverviewLink`，全部 `import type { OpenApi } from "@risk-platform/contracts"` 后取自 `OpenApi.components["schemas"][...]`（frozen 生成 authority），非手写替代契约。
- `apps/web/src/views/admin/AdminDashboardView.vue`：
  - 移除固定 health 数组（原 `[{name:'身份与权限服务',...}]`）、3 条固定 attention item、3 条固定 audit activity `<li>`。
  - 三段改为 `v-for` 消费 `AdminOverview.health`/`attention`/`recentAudit`，逐项渲染真实 `label/summary/status/occurredAt/actorName/result` 等。
  - 链接语义：`navigateLink(link)` 以 `router.push({ path, query: { ...link.query } })` 透传契约 path+query，不硬编码；health item `link` 为 `null` 时 no-op（仅 `AI_PROVIDER` 可有 link）；attention/recentAudit link 导航至契约真实 path。
  - loading/empty/error/unavailable：health/attention/recentAudit 各自 v-if/v-else-if 链覆盖「未加载」「section=null 且 `unavailableSections` 有对应项（FORBIDDEN/TIMEOUT/DEPENDENCY_FAILURE）」「空数组」「有数据」；顶部 fetch error 渲染 `role="alert"` 错误条 + 重试，不崩溃页面；`generatedAt` 驱动「系统状态已更新」时间。
  - metrics（users/roles/permissions/imports/ai）保留既有真实调用，独立 try/catch 优雅降级，不影响 overview 三段权威状态。
  - health rollup badge：`overallHealthStatus` 由 item 状态聚合（UNAVAILABLE 主导 DEGRADED，空数组显式 EMPTY），badge tone 动态。
- `apps/web/src/utils/admin-overview.ts`（新）：presentation helpers（`overallHealthStatus`/`overallHealthLabel`/`healthStatusLabel`/`healthGlyph`/`attentionStatusLabel`/`attentionStatusClass`/`auditResultLabel`/`unavailableReasonLabel`/`findUnavailable`），全部以 generated enum union 为 key，类型安全。
- `apps/web/src/utils/admin-overview.test.ts`（新）：7 个 vitest，覆盖 health rollup（含 UNAVAILABLE 主导、EMPTY）、per-item label/glyph、attention 严重度 label+class、audit result label、3 个 unavailable reason label、`findUnavailable` 命中/未命中。

### 不变式保持

- 无固定 success/sample 业务数组（已全部移除）。
- 权限/路由不变：`router/index.ts`、`AdminShell.vue` 未改，`/admin` 路由守卫不动；section 级 FORBIDDEN 由后端 `unavailableSections` 表达，前端不越权、不将 overview item 作授权凭证（目标页重新授权/查询）。
- 严格消费生成类型：无 `any` cast 覆盖生成类型；非空断言已改为 optional chaining（`!healthItems?.length`），即便后端违反 ADR 0023「null section 必有 unavailable 项」也不抛 `null.length`，优雅降级为 empty 状态。
