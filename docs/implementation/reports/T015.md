## 实施摘要

- 新增 metadata-only audit 查询 schema、service 和 `/api/admin/audit-logs*` 路由。
- 支持授权 summary、options、分页查询、详情和 PostgreSQL hash-chain integrity 查询。
- 遵循 ADR 0017：快照字段固定为 `null`，敏感度为固定安全值，summary/context 仅由受控字段派生。
- 新增有界 CSV/XLSX metadata-only 导出；reason 强制校验，成功和失败导出均追加自身审计事件，单次最多 10,000 条。
- 非 `SYSTEM_ADMIN` 查询通过 `project_scope_predicate` 限定 `projectId`，权限由 `admin.audit.view` / `admin.audit.export` 分离保护。
