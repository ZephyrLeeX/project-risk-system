# T004 实施报告

- **Task:** T004 — Add Agent and weekly-report capability schemas
- **Status:** REVIEW_PASSED
- **Review:** REVIEW_PASSED（独立复审通过）

## 实施摘要

- 新增 `agent` 与 `weekly_reports` bounded-context ORM models，并登记到统一 SQLAlchemy metadata。
- 新增唯一 Alembic revision `20260811_0004`（基于 T041 head `20260811_0003`）：创建 Agent
  conversation/message/event/confirmation 与 weekly aggregate/item 六张表、enum、唯一键、检查约束、索引和外键。
- Independent Review 发现 ADR 0021 已明确要求 `WEEKLY_REPORT_REBUILD` durable task kind，而 T041 初始
  registry 尚未包含该值。依据 ADR 0018「新增 kind 必须通过显式设计和 migration 加入统一 registry」及
  ADR 0021 的明确 rebuild 设计，本 revision 以 additive PostgreSQL enum value 和 reliability registry
  补齐该 kind；不新增任务表、字段或第二迁移。
- PostgreSQL insert trigger 原子递增会话计数器，强制 message/event sequence 从 1 连续且每会话唯一。
- Agent event 以 `RESTRICT` 引用 T041 `durable_tasks`；weekly item 对 aggregate、邮件、候选、风险、待办
  均为 `RESTRICT` 外键，防止清理破坏物化事实。
- 新增 schema note 和 metadata/PostgreSQL focused tests；未实现 API、worker、service、rebuild、confirmation
  消费或 retention execution。
