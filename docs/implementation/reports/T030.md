## 批准的 REPORT category contract

ADR 0029 将 PostgreSQL 当前 active `RiskCategory` 定为 `REPORT.categoryId` 唯一权威来源。Agent
复用 ADR 0026 `RISK_CATEGORY_OPTIONS_V1`，Provider 仅选择 attempt-local opaque option；服务端映射为
本地 UUID，并把 `categoryId` 与 `categoryBindingDigest` 纳入 ADR 0019 canonical content、content digest
和一次性 token 绑定。

preview 签发前与 confirmation transaction 内都重新校验分类。缺失/未知 option 非 retryable；签发前
mapping stale 按既有 `AGENT_EXECUTION` budget 重试并重建 options；确认时 missing、disabled 或 binding
stale 返回 `AGENT_CONFIRMATION_CONTENT_MISMATCH`，不消费 token 且不产生业务写入。不存在默认分类、
文本推断、自由 taxonomy、历史或 legacy fallback。

协议显式升级为 `AGENT_PROVIDER_EXECUTION_V2`；V1 response 和缺少分类绑定的 legacy `REPORT` token
fail closed。confirm endpoint、空 request、TTL、owner/scope、replay、SSE envelope 以及
`PROCESS`/`RESOLVE` 业务语义保持兼容。audit/log 仅增加固定 version/count/failure code，不保存 option
集合、UUID mapping、分类文本、canonical content 或 Provider output。
