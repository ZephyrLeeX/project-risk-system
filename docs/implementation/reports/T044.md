## 实施摘要

- 迁移 NestJS `admin.controller.ts` `@Get("projects/options")` 至 FastAPI
  `GET /api/admin/projects/options`，返回 `ProjectOption[]`，复用既有
  `@risk-platform/contracts` `ProjectOption` 类型，不新增持久化、不新增 ADR。
- 对 T012 既有 `admin/options` 模块**仅追加**：`schemas.py` 新增
  `ProjectOptionResponse`（`id`/`externalCode: str|null`/`name`/`departmentName: str|null`，
  `extra="forbid"`），`service.py` 新增 `AdminOptionsService.list_projects()`，
  `api.py` 新增 `list_projects` 路由。既有 `list_departments` 路由、`DepartmentResponse`
  契约与 T012 冻结面**未修改**（diff 逐行确认 additive-only）。
- 权限/scope：`admin.scope.manage` 经 `require_permissions` 守卫；无 data-scope 过滤
  （与 NestJS 一致——此为 admin scope-management 选择器，返回全部非归档项目）。
- 查询语义严格对齐 NestJS `admin-options.service.ts` `projects()`：
  - `where: { status: { not: ProjectStatus.ARCHIVED } }` → `Project.status != ProjectStatus.ARCHIVED`
  - `orderBy: [{ name: "asc" }]` → `order_by(Project.name.asc())`
  - `take: 500` → `.limit(500)`
  - `department: { select: { name: true } }` + `project.department?.name ?? null`
    → `select(Project, Department.name).join(Department, ..., isouter=True)`，
    `departmentId` 为空时 `departmentName` 为 `null`（LEFT JOIN）。
- 信封/错误：`ApiResponse{code,message,data,traceId}`（`ok()` → `code:"OK"`）；
  缺权限 → `ApiError(403, "FORBIDDEN", ...)`，与 NestJS `ForbiddenException` 语义一致。
- composition/main：**无变更**。`options_router` 已在 `main.py` 注册、
  `admin_options_service` 已在 `composition.py` 组装（T012 既存），T044 纯追加路由/方法，
  无需触碰 T040 冻结的 composition root。
