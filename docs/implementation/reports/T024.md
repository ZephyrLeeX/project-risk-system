## 实施摘要

在 Python mailbox bounded module 内实现 scheduled/manual/retry UID synchronization。IMAP worker 只在内存中读取 UIDVALIDITY、UID 和 envelope metadata；正文、附件和原始 source 不进入 PostgreSQL、Redis、Celery payload、日志或 audit。新增 UIDVALIDITY-only handoff、fetch/handoff/parse/AI-review 阶段事实、批次 terminal 统计、显式 reset/rebaseline、retry dispatch 和批次 reconciliation。每个新 handoff 与下游 `ATTACHMENT_PARSE` durable task 及首条 transactional outbox 在同一 PostgreSQL transaction 中提交。
