## 实施摘要

- 按最终 `schema.prisma` 与全部 13 个历史 migration 建立单一 Alembic baseline head：`20260810_0001`。
- 最终权威 Prisma schema 当前包含 28 个 model；SQLAlchemy model 按 `admin`、`auth`、`rbac`、`projects`、`imports`、`risks`、`todos`、`timeline`、`system_config`、`ai_providers`、`audit`、`mailbox` 领域模块组织，没有形成巨型全局 `models.py`。
- 保留 PostgreSQL UUID、`TIMESTAMPTZ(3)`、`DECIMAL(18,2)`、JSONB、BIGINT、native enum、nullability、default、PK、unique index、普通 index、check、FK 及 `ON DELETE` / `ON UPDATE` 语义。
- 新增 async SQLAlchemy engine、session factory、显式 transaction boundary 与 disposal 基础设施；仅接受 `postgresql+psycopg`。
- 为 25 个 Prisma `@default(uuid())` column 配置 Python-side `default=new_uuid`，为全部 17 个 `@updatedAt` column 配置 aware UTC insert default 与 `onupdate`，不改变 DDL/server default。
- 定义严格递归 `JSONValue`，覆盖 JSON object、array、string、number、boolean 与 null；`DATE` column 使用 `datetime.date` annotation。
- Alembic baseline 仅迁移结构，不包含 Seed、历史数据回填、runtime `create_all` 或新能力表。
