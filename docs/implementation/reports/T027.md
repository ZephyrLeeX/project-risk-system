## DESIGN_GAP

实施阶段发现批准合同无法由当前权威源满足：

- ADR 0021 与冻结设计要求周归属只使用邮件 `sent_at`，缺失时使用不可变 `received_at`；延迟同步不得改变所属周。
- 当前 `MailMessage` 只有 `sentAt`、`processedAt`、`createdAt`，没有 `receivedAt`。
- `MailSourceHandoff.envelopeMetadata` 只持久化 `sent_at`，当前 source service 也没有暴露或持久化不可变接收时间。
- 使用 `createdAt` 或 `processedAt` 作为 fallback 会把同步/处理时间当成接收时间，导致延迟同步改变所属周，违反批准设计。

T027 明确将新增邮件存储列为 out-of-scope，且 stop condition 要求在 required source service 不可用时停止。因此需要先由
批准设计明确邮件接收时间的来源语义（例如 IMAP `INTERNALDATE` 是否为权威事实）、持久化位置、migration ownership 与既有
邮件的 backfill/fail-closed 规则，再恢复 T027。
