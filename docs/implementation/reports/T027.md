## 实施摘要

- 新增 weekly-report summary/detail API、schema、PostgreSQL materialization、revision/idempotent rebuild、
  invalidation、freshness/stale 与 authoritative-source reconciliation 模块入口。
- 周归属严格使用 `COALESCE(sentAt, receivedAt)`，以 `Asia/Shanghai` 的星期一为周界；读取时重新执行
  当前用户 project scope，响应仅包含批准的最小字段。
- 邮件 ingestion 从 IMAP `INTERNALDATE` 获取 `receivedAt`；缺失或非法时冻结首次 durable handoff
  PostgreSQL transaction timestamp。时间统一为 UTC `timestamptz(3)`，retry/refetch 不重算。
- `MailMessage` 身份升级为 `(mailboxConfigId, uidValidity, imapUid)`；数据库 trigger 同时保护该身份和
  `sentAt`/`receivedAt`/provenance 不可修改。legacy `sentAt` 因无法证明 timezone 合法性而保守回填 `NULL`。
- shared FastAPI/Celery composition 未修改；T027 提供模块 entry points，由 T040 统一装配。
