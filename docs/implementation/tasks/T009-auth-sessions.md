- **Task ID:** T009
- **Title:** Migrate authentication and sessions
- **Status:** READY / TODO
- **Objective:** Reproduce login/session/change-password/logout, lockout and secure Cookie behavior in FastAPI.
- **Design baseline:** Design §§3,7; compatibility/global constraints.
- **Authoritative source references:** legacy `auth/**`, password/session tests, Prisma User/Session, frontend auth API/store/views.

- **Scope:** Password hashing/policy, lock counter, session token hashing/revocation, forced change, endpoints and audit calls.
- **Explicit out-of-scope:** Authorization/data scope and admin user mutation.
- **Expected read set:** Named auth/frontend/schema sources.
- **Expected write set:** Python auth module and tests; no frontend writes.
- **Contracts/invariants:** Same endpoints/envelopes/Cookie behavior; HttpOnly/Secure/SameSite; session secrets protected; failed actions audited.
- **Acceptance criteria:** Positive/negative/lock expiry/concurrency/forced-change/revocation contract tests pass.
- **Validation:** PostgreSQL API integration and Cookie tests; Ruff/mypy/pytest.
- **Required deliverables:** Auth routes/services/repositories/schemas/tests.
- **Stop conditions:** Legacy observable contract conflicts with approved security requirements.
- **Known integration risks:** Reverse-proxy Secure Cookie testing and T010 dependency injection.
