# T011 — Migrate user administration
- **Task ID:** T011
- **Title:** Migrate user administration
- **Status:** READY / TODO
- **Objective:** Implement compatible admin user query/mutation, status, unlock, password reset and project assignment APIs.
- **Design baseline:** Design §3 and global auth/RBAC/audit rules.
- **Authoritative source references:** legacy `admin/users.service.ts`, controller/DTO/mapper; frontend `api/admin.ts`; relevant contracts.
- **Relevant ADR IDs:** 0001, 0004, 0008, 0011, 0015.
- **Dependencies:** T005, T006, T010.
- **Scope:** `/api/admin/users*`, summaries, records, project scopes, transactional audit/session revocation.
- **Explicit out-of-scope:** Role definition changes, admin overview.
- **Expected read set:** Named admin/auth/RBAC sources.
- **Expected write set:** Python `admin/users/**` module/tests only; do not edit role/options or shared app composition files.
- **Contracts/invariants:** Initial/reset password returned once; disable/reset revokes sessions; scope assignment validates target projects.
- **Acceptance criteria:** Legacy parity and unauthorized/invalid/self-impact negative cases pass.
- **Validation:** API contract + PostgreSQL transaction tests; Ruff/mypy/pytest.
- **Required deliverables:** Routes/schemas/service/repository/audit tests.
- **Stop conditions:** Mutation requires a new role/scope semantic.
- **Known integration risks:** User/project-scope concurrent edits.
