- **Design baseline:** Design §§8,9,11.
- **Authoritative source references:** ADRs 0009/0018-0021; **ADR 0032 (approved DG-05 numeric thresholds & release-gate semantics)**; T037 release candidate.

- **Explicit out-of-scope:** HA/multi-node and unapproved tuning architecture; real external AI/IMAP throughput (deferred to T039).

- **Stop conditions:** DG-05 unresolved (now resolved) or production-like resources unavailable.
- **Known integration risks:** Environment noise and unrealistic AI/IMAP substitutes (substituted-path evidence recorded explicitly; not a best-effort PASS; real external E2E deferred to T039).
