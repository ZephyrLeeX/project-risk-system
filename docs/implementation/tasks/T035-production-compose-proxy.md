# T035 — Build production Compose and HTTPS proxy topology
- **Task ID:** T035
- **Title:** Build production Compose and HTTPS proxy topology
- **Status:** READY / TODO
- **Objective:** Define single-server Compose for proxy, Python API, worker, scheduler, PostgreSQL and Redis with persistent storage and health checks.
- **Design baseline:** Design §§4,7,9.
- **Authoritative source references:** existing Compose/env/storage layout; Python process contracts as completed.
- **Relevant ADR IDs:** 0001, 0003, 0006, 0009, 0010, 0014, 0016.
- **Dependencies:** T031, T032, T033, T034, T040.
- **Scope:** Dockerfiles, Compose profiles, proxy config, secrets/read-only files, volumes, health/startup ordering and operational docs.
- **Explicit out-of-scope:** Kubernetes/HA, real certificates/secrets, backup logic.
- **Expected read set:** Infra/env/manifests/design.
- **Expected write set:** Production Compose file(s), `infra/proxy/**`, Python Docker files, env examples and deployment docs; do not write `infra/backup/**`. T035 is the sole owner of production Compose/proxy/env-example files.
- **Contracts/invariants:** Production has no NestJS service; TLS/security headers; Redis not durable fact; no default secrets.
- **Acceptance criteria:** Config renders; images build; stack health/failure behavior passes with test secrets/cert.
- **Validation:** `docker compose config`, image build, stack smoke and header tests.
- **Required deliverables:** Compose/Docker/proxy/env/runbook.
- **Stop conditions:** Would commit credentials/certificates.
- **Known integration risks:** Worker health and proxy SSE buffering.
