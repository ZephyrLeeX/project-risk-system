# T015 — Migrate audit search, integrity and export APIs
- **Task ID:** T015
- **Title:** Migrate audit search, integrity and export APIs
- **Status:** READY / TODO
- **Objective:** Provide compatible scoped audit query/detail/summary/options, chain integrity and metadata-only CSV/XLSX export.
- **Design baseline:** Design §7.
- **Authoritative source references:** legacy `audit/**`, frontend audit API/view/contracts.
- **Relevant ADR IDs:** 0008, 0011, 0014, 0017.
- **Dependencies:** T006, T010.
- **Scope:** `/api/admin/audit-logs*`, filters/pagination, metadata-only projection, export-audits-itself.
- **Explicit out-of-scope:** Repair/purge and module event production.
- **Expected read set:** Named audit sources/tests.
- **Expected write set:** Python audit HTTP/export modules/tests.
- **Contracts/invariants:** Append-only; no snapshot/payload fields are exposed or reconstructed; invalid chain visible; export reason required.
- **Acceptance criteria:** Contract parity through an ADR 0017-compliant metadata projection; injection, authorization, no-payload, invalid-chain and self-audit tests pass.
- **Validation:** API/PostgreSQL/file tests; Ruff/mypy/pytest.
- **Required deliverables:** Routes/schemas/exporter/tests.
- **Stop conditions:** Export would expose prohibited content.
- **Known integration risks:** Large export memory and transaction ordering.
