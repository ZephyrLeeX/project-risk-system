# T028 — Build Agent conversations and authorized query tools
- **Task ID:** T028
- **Title:** Build Agent conversations and authorized query tools
- **Status:** TODO
- **Objective:** Persist Agent conversations and expose a whitelist of read-only business tools that reuse domain services and current authorization.
- **Design baseline:** Design §6 Agent; `CONTEXT.md` Agent definition.
- **Authoritative source references:** ADRs 0019/0021; T004 schema; T020-T027 domain interfaces.
- **Relevant ADR IDs:** 0004, 0005, 0012, 0013, 0015, 0019, 0021.
- **Dependencies:** T004, T010, T014, T020, T022, T026, T027.
- **Scope:** Conversation create/continue/history/help per contract, tool registry, schemas, permission/scope recheck, provenance/data-time/trace metadata.
- **Explicit out-of-scope:** SSE orchestration and all writes.
- **Expected read set:** Approved contract and domain service interfaces.
- **Expected write set:** Python agent conversation/tool modules/tests.
- **Contracts/invariants:** No arbitrary SQL; tools do not access foreign tables directly; historical views use current scope.
- **Acceptance criteria:** Tool whitelist, role/scope matrix, prompt-injection and retention metadata tests pass.
- **Validation:** PostgreSQL service/API tests with fake Provider.
- **Required deliverables:** Persistence/repository, tool registry, schemas/tests.
- **Stop conditions:** A query lacks an authorized domain service.
- **Known integration risks:** Data leakage through counts/provenance.
