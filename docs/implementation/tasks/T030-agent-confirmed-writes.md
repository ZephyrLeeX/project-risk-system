# T030 — Execute Agent confirmed writes
- **Task ID:** T030
- **Title:** Execute Agent confirmed writes
- **Status:** READY
- **Objective:** Confirm report/process/resolve previews through single-use tokens and existing domain transactions.
- **Design baseline:** Design §6 Agent.
- **Authoritative source references:** ADRs 0019/0020/0029; ADR 0026 category option projection; T021/T022 domain services; T029 preview token.
- **Relevant ADR IDs:** 0004, 0008, 0013, 0015, 0016, 0019, 0020, 0026, 0028, 0029.
- **Dependencies:** T004, T006, T010, T021, T022, T029.
- **Scope:** Bounded `AGENT_PROVIDER_EXECUTION_V2` category option projection and normalized `REPORT` preview binding; REST confirm operations, canonical content binding, expiry/one-use/replay handling, idempotency and audit.
- **Explicit out-of-scope:** Writes from SSE, bypass domain rules, new risk states.
- **Expected read set:** Addenda, Agent execution/preview code and risk/category domain contracts.
- **Expected write set:** Python Agent category projection/preview normalization plus confirmation module/routes/tests; no shared FastAPI/Celery composition or T040 write-set.
- **Contracts/invariants:** Token binds user+conversation+content+server-mapped active category; confirmation locks and revalidates category binding in one transaction; current permission/scope rechecked; retries do not duplicate; no default/inferred/free-text category.
- **Acceptance criteria:** Success/expired/wrong-user/tampered/replay/concurrent/rollback plus empty/unknown/stale/disabled/missing category, legacy token and `PROCESS`/`RESOLVE` compatibility tests pass.
- **Validation:** PostgreSQL API concurrency tests.
- **Required deliverables:** Confirm route/service/token repository/tests.
- **Stop conditions:** An approved operation cannot be expressed through the existing domain services.
- **Known integration risks:** Replay races and transaction lock ordering.
