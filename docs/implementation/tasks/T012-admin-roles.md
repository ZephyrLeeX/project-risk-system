# T012 — Migrate role and permission administration
- **Task ID:** T012
- **Title:** Migrate role and permission administration
- **Status:** READY / TODO
- **Objective:** Implement compatible role, permission and department option administration.
- **Design baseline:** Design §3; four default roles/five scopes.
- **Authoritative source references:** legacy roles/admin-options/role-policy/controller; frontend admin API and contracts.
- **Relevant ADR IDs:** 0004, 0008, 0011, 0015.
- **Dependencies:** T005, T006, T010.
- **Scope:** Role list/create/update/delete, permission list, department options and protected-system-role rules.
- **Explicit out-of-scope:** User CRUD and project option ownership.
- **Expected read set:** Named legacy files/tests/schema.
- **Expected write set:** Python `admin/roles/**` and `admin/options/**` modules/tests only; do not edit user or shared app composition files.
- **Contracts/invariants:** System-role constraints and permission codes remain stable; in-use roles cannot be unsafely removed.
- **Acceptance criteria:** Contract parity, policy and audit negative tests pass.
- **Validation:** API/PostgreSQL tests; Ruff/mypy/pytest.
- **Required deliverables:** Routes/services/schemas/tests.
- **Stop conditions:** Proposed edit changes default permission boundaries.
- **Known integration risks:** Seed drift and role-user race.
