# T027 — Implement weekly report aggregation
- **Task ID:** T027
- **Title:** Implement weekly report aggregation
- **Status:** READY
- **Objective:** Expose authorized current-week report summary/detail from processed mail and published business state.
- **Design baseline:** `CONTEXT.md` “本周周报”; design §§3,6.
- **Authoritative source references:** ADRs 0019/0021 including the approved immutable received-time addendum; T004/T024/T025/T026 schemas and services; `project-risk-system/apps/web/src/views/DashboardView.vue` only for visible placement.
- **Relevant ADR IDs:** 0004, 0007, 0011, 0015, 0019, 0021.
- **Dependencies:** T004, T010, T020, T025, T026.
- **Scope:** ADR 0021's additive immutable envelope-time metadata revision and T024/T025 ingestion compatibility wiring; aggregate creation/rebuild/invalidation path, Shanghai-week query, sent/received fallback, project-scope filtering, ADR 0019 summary/detail schemas and endpoints.
- **Explicit out-of-scope:** Mail body/attachment/header storage, redesigning mail synchronization/parsing/AI/cursor semantics, Agent, frontend wiring.
- **Expected read set:** Named definitions/schema/addendum.
- **Expected write set:** Next serialized Alembic revision; mailbox envelope/handoff/message model and ingestion-time metadata wiring/tests; Python weekly-report module/OpenAPI/tests.
- **Contracts/invariants:** `received_at` follows ADR 0021's immutable source/provenance/fallback contract; retry/refetch and delayed processing do not change week; current authorization reevaluated; only minimized content returned.
- **Acceptance criteria:** Boundary/DST-neutral/fallback/delay/late-update/rebuild/scope/empty-state tests match the approved contract and prove aggregate/source consistency.
- **Validation:** PostgreSQL API tests with fixed clocks.
- **Required deliverables:** Routes/query service/schemas/tests.
- **Stop conditions:** A required source service or the approved aggregate contract is unavailable.
- **Known integration risks:** Timezone boundary and duplicate project/mail counting.
