# T029 — Stream Agent answers and mutation previews
- **Task ID:** T029
- **Title:** Stream Agent answers and mutation previews
- **Status:** READY
- **Objective:** Implement approved SSE text/progress/error/preview events without performing business mutations.
- **Design baseline:** Design §6; ADR 0016.
- **Authoritative source references:** ADRs 0019/0020/0028; T008 worker boundary; T028 tools; `project-risk-system/apps/web/src/views/DashboardView.vue`.
- **Relevant ADR IDs:** 0005, 0006, 0011, 0013, 0014, 0016, 0019, 0020, 0028.
- **Dependencies:** T004, T007, T008, T010, T014, T028.
- **Scope:** Provider orchestration through ADR 0020/0028, intent/arguments validation, ADR 0019 SSE framing/IDs, disconnect/timeout/resume behavior, structured preview/token issue boundary, and an explicit dependency-injected module-local `AGENT_EXECUTION` Worker entrypoint compatible with T008.
- **Explicit out-of-scope:** Confirmed writes, frontend, and all shared production FastAPI/Celery composition, handler-map merging, dependency construction, lifecycle and registration wiring owned by T040.
- **Expected read set:** Addenda, Provider/Agent interfaces.
- **Expected write set:** Python agent streaming/orchestration modules, its module-local Worker entrypoint, Agent-owned schema/migration, OpenAPI and tests. It excludes shared FastAPI/Celery bootstrap/composition files.
- **Contracts/invariants:** Stream never mutates risk/todo/timeline; events identify conversation/message/trace; explicit failure, no mock answer.
- **Acceptance criteria:** Approved event sequences, disconnect/reconnect, timeout, malformed-model and no-write assertions pass; an isolated Celery app can register the module-local handler mapping and a real test worker can discover and execute `AGENT_EXECUTION` with a fake Provider. Production shared-app registration is deferred to T040 and is not a T029 acceptance condition.
- **Validation:** ASGI streaming integration tests plus an isolated Celery app using T008 `register_executor`, the T029 module-local entrypoint, a real test worker and a fake Provider.
- **Required deliverables:** SSE route/orchestrator/event schemas/tests and the module-local `AGENT_EXECUTION` Worker entrypoint/handler mapping contract consumed by T040.
- **Stop conditions:** A required ADR 0019/0020 contract cannot be expressed through the declared boundaries.
- **Known integration risks:** Proxy buffering and cancellation cleanup.
