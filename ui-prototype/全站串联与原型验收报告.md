# 项目风险管理平台——全站串联与原型验收报告

- 验收日期：2026-07-26
- 验收范围：`ui-prototype` 目录内 11 个 HTML 页面及其 CSS、JavaScript 资源
- 验收对象：高保真交互原型，不包含真实后端、数据库、邮箱服务器、AI 服务和 Excel 解析服务
- 验收结论：**通过原型阶段验收，可进入接口设计与前端工程化实现阶段**

## 1. 本次验收修正

### 1.1 登录后的角色入口串联

原登录页提交后固定进入业务看板，导致后台管理页面无法通过正常登录链路到达。本次已优化为：

- 账号填写 `admin`、`system_admin` 或 `system-admin`：进入第 3 页「后台管理首页」。
- 其他非空账号：进入第 2 页「Web 风险看板」。
- 密码在原型阶段只校验非空，不做真实身份认证。
- 登录页已增加原型验收提示，不改变正式系统的功能模块。

修正后，从登录页可以覆盖业务端与管理端全部 11 个页面。

## 3. 页面级功能验收

### 01 登录

- 账号、密码必填校验。
- 密码显示/隐藏。
- 记住账号。
- 忘记密码提示。
- 按原型账号类型分别进入业务端或后台管理端。

### 02 Web 风险看板

- 项目数、风险数、高风险、待回款和已回款指标卡。
- 本周重点关注。
- 项目风险、部门回款、管理员待办、应收与回款、风险时间线、已解除风险六个页签。
- 风险搜索及等级、类别、负责人筛选。
- 风险详情弹框保留风险描述、证据/信息来源、建议措施、关联行动项、同项目其他风险等完整内容。
- 周报详情弹框保留关键要点、涉及项目列表、提取的全部风险、关联行动项等完整内容。
- Agent 智能对话抽屉和模拟问答。

### 03 后台管理首页

- 用户、角色、导入批次、API 服务统计。
- 系统健康状态、待关注事项、最近导入和审计记录。
- 管理模块入口与对应页面跳转。

### 04 用户管理

- 用户统计、搜索、角色/状态/部门筛选。
- 新增和编辑用户。
- 角色分配、项目数据范围、账号状态。
- 启用、停用、解锁、重置密码、查看记录。
- 批量操作与确认反馈。

### 05 角色权限

- 预置角色与自定义角色切换。
- 权限树选择、搜索、重置和保存。
- 角色新增、复制、启停和删除。
- 角色权限对照表及角色用户入口。
- 已按业务边界保留风险管理员、项目经理和查看/审计员的数据范围差异。

### 06 项目数据导入

- Excel 模板下载入口。
- 项目清单和回款数据文件选择、格式提示与解析状态。
- Sheet 识别、数据预览、异常提示、项目匹配确认。
- 草稿保存、警告确认、发布导入。
- 导入历史、状态筛选、错误下载和批次回滚。

### 07 API Key 管理

- AI 服务统计、搜索和状态筛选。
- 新增/编辑服务商、服务地址、模型、API Key、有效期和调用参数。
- API Key 显示控制、连接测试、批量测试。
- 默认服务切换、密钥轮换、使用统计和调用日志。
- API Key 不在列表和日志中明文展示。

### 08 系统配置

- 风险类别、风险等级与颜色配置。
- 邮箱同步间隔、主题关键词和风险关键词。
- 项目别名维护。
- 安全策略、通知策略和变更历史。
- 全局保存、发布确认和放弃修改。

### 09 审计日志

- 操作人、模块、动作、结果和日期范围筛选。
- 失败、敏感操作和活跃操作人统计入口。
- 审计详情、资源 ID、Trace ID 和复制操作。
- 导出范围、格式和用途说明确认。

### 10 风险管理员个人邮箱配置

- 邮箱类型、邮箱地址、授权码、IMAP 服务器、端口、加密方式和文件夹。
- 周报关键词、发件人规则、同步时间范围、附件读取和 AI 分析开关。
- 连接测试、保存配置、取消修改、立即同步、停用邮箱。
- 查看邮箱同步结果并进入第 11 页。

### 11 邮箱同步结果

- 同步批次及成功、风险、跳过和失败指标。
- 邮件结果与同步批次两个页签。
- 关键词、状态、批次筛选和待处理提醒。
- 邮件详情抽屉、失败重试和关联风险处理入口。
- 手动同步及结果反馈。

## 5. 原型阶段边界

以下交互目前为前端模拟，进入开发阶段后需要接入真实接口：

- 登录认证、会话、账号锁定和权限校验。
- 用户、角色、权限、项目范围的数据库持久化。
- Excel 文件上传、字段映射、解析、校验、发布和回滚。
- API Key 加密存储、连接测试、轮换和调用日志。
- 邮箱授权、IMAP 连接、邮件同步、附件读取和同步批次。
- AI 风险提取、项目匹配、风险审核和 Agent 对话。
- 审计日志写入、检索和文件导出。

应用内浏览器对本地 `file://` 页面执行自动截图时受到安全策略限制，因此本报告中的浏览器视觉结论基于此前逐页人工审阅与本轮代码级检查；本轮未通过其他浏览器或本地服务器绕过该限制。
