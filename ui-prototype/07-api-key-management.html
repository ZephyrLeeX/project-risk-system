CREDENTIAL SECURITY

API Key 安全规则

01
加密存储

API Key使用AES-256-GCM保存，加密主密钥不进入数据库和代码仓库。

02
禁止回显

保存后页面仅展示掩码与尾号；编辑时密钥输入框保持空白。

03
最小化使用

密钥仅在服务端解密并短时用于调用，不写入提示词、浏览器或业务数据。

04
日志脱敏

配置、测试、启停和默认服务切换均记录审计，但不会记录完整密钥和原始响应。
